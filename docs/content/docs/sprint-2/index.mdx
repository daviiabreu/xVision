title: Sprint 2

---

A Sprint 2 transforma as decisões técnicas da proposta em uma primeira versão funcional. Os
componentes de campo, bola, jogadores e instante da finalização foram priorizados para desbloquear
as métricas, enquanto backend e frontend avançaram em paralelo.

<Callout type="idea" title="Foco da sprint">

O resultado esperado é um fluxo integrado para processar um clipe curto que já contenha uma
finalização, produzir percepções verificáveis e disponibilizar as métricas calculadas para o
frontend. Adaptação e otimização no hardware de borda permanecerão para uma etapa posterior.

</Callout>
