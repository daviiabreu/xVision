Esta sprint transforma o problema apresentado pela Footstats em uma proposta verificável para
extrair características de finalizações de futebol com visão computacional em edge computing.
O conteúdo parte do valor esperado para o parceiro, delimita o produto, registra requisitos e
riscos, compara alternativas técnicas e organiza as decisões que serão testadas nas próximas
sprints.

<Callout type="idea" title="Escopo do MVP">

A entrada é um clipe curto que já contém uma finalização, o dispositivo de borda processa o
vídeo e produz um evento estruturado, enquanto o backend calcula o xG. Encontrar finalizações
em uma transmissão completa, operar em produção ou implementar a arquitetura de escala são
evoluções futuras fora do escopo atual.

</Callout>
